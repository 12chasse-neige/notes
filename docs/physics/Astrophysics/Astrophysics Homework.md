# Astrophysics Homework

## 1. 现代天体物理的代表性成就、当前主要前沿问题及其对基本物理的推动作用

### 1.1 现代天体物理的代表性成就

**（1）宇宙学标准模型（ΛCDM）的确立**
- 1965 年发现宇宙微波背景辐射（CMB，Penzias & Wilson，1978 年诺贝尔奖），为大爆炸宇宙学奠定观测基础；
- COBE（1992 年发现 CMB 各向异性，2006 年诺贝尔奖）→ WMAP → Planck 卫星，把宇宙学参数（年龄 138 亿年、物质/重子密度、谱指数等）测定到百分之一量级，确立了"宇宙学常数 + 冷暗物质"的标准模型。

**（2）暗能量的发现（1998 年，2011 年诺贝尔奖）**
Ia 型超新星巡天发现宇宙正在加速膨胀，揭示约 68% 的宇宙能量成分为具有负压强的"暗能量"，是 20 世纪物理学最重大的意外发现之一。

**（3）引力波天文学与多信使天文学的诞生（2017 年诺贝尔奖）**
- 2015 年 LIGO 首次直接探测双黑洞并合引力波（GW150914）；
- 2017 年 GW170817 双中子星并合被引力波、伽马射线（GRB 170817A）及全电磁波段联合观测，开启多信使天文学时代，并确认千新星是 r 过程重元素（金、铂等）的主要来源；
- 2023 年脉冲星计时阵列（NANOGrav 等）发现纳赫兹引力波背景的证据，超大质量黑洞双星演化得到检验。

**（4）黑洞从理论走向直接观测**
- 通过银河系中心恒星轨道长期监测证明 Sgr A* 是 ~400 万太阳质量的超大质量黑洞（2020 年诺贝尔奖，Genzel 与 Ghez；理论部分 Penrose）；
- 事件视界望远镜（EHT）利用毫米波甚长基线干涉分别于 2019 年（M87*）和 2022 年（Sgr A*）获得黑洞"阴影"图像，与广义相对论预言高度一致。

**（5）系外行星科学的爆发（2019 年诺贝尔奖）**
1995 年发现首颗主序星旁的系外行星（飞马座 51b）以来，凌星、视向速度、微引力透镜、直接成像等手段已确认超过 5000 颗系外行星，揭示行星系统的惊人多样性（热木星、超级地球、亚海王星、自由漂浮行星等），JWST 已开始对系外行星大气进行分子光谱表征。

**（6）致密天体与高能天体物理**
- 脉冲星的发现与双脉冲星对广义相对论的精确检验（1974、1993 年诺贝尔奖）；
- X 射线天文学（1970 年 Uhuru 卫星起）确立中子星/黑洞吸积物理；磁星、超亮 X 射线源（ULX）等极端天体证认；
- 伽马射线暴（1967 年 Vela 卫星发现）1997 年由 BeppoSAX 定位余辉，证认为宇宙学距离上的恒星级爆发，BeppoSAX 之后 Swift、Fermi 时代使其成为研究早期宇宙和相对论性激波的标准烛光。

**（7）中微天体物理（2015 年诺贝尔奖）**
太阳中微子"失踪"问题由 SNO 与 Super-Kamiokande 解决——中微子振荡证明中微子有质量；1987A 超新星中微子探测；2013 年 IceCube 发现河外天体中微子，2018 年首次实现中微子（TXS 0506+056）与伽马射线的联合观测。

**（8）其他重要成就**
- LAMOST、SDSS 等大规模光谱巡天与 Gaia 卫星对银河系上十亿恒星的精确测绘（"银河系考古"）；
- ALMA 对原行星盘亚毫米波成像（如 HL Tau 的环隙结构）直接观测行星形成过程；
- JWST 发现红移 z>13 的星系，将星系形成观测推进到宇宙大爆炸后 3 亿年内；
- 快速射电暴（FRB，2007 年发现）的发现、重复暴定位及其与磁星 SGR 1935+2154 的关联；
- 大规模数值宇宙学模拟（Millennium、IllustrisTNG 等）将宇宙结构形成理论定量化。

### 1.2 当前天体物理的主要前沿问题

1. **暗物质本质**：其粒子属性（WIMP、轴子、原初黑洞或其他？）仍未知；冷暗物质模型在小尺度（卫星星系缺失、核-尖峰问题）上的张力。
2. **暗能量本质与宇宙学危机**：宇宙学常数还是动力学场或修改引力？哈勃常数（H₀）张力超过 5σ，S₈ 张力持续；DESI 巡天甚至暗示暗能量可能随时间演化。
3. **黑洞的形成、演化与强引力检验**：z>7 超大质量黑洞如何快速长成？中等质量黑洞是否存在？视界附近广义相对论（Kerr 度规、无毛定理）的精确检验。
4. **引力波天文学的全面展开**：双黑洞并合的形成通道与并合率；LISA 频段的超大质量黑洞并合；原初引力波与暴胀物理；连续引力波。
5. **宇宙黎明与再电离**：第一代恒星（Pop III）何时、如何点燃？21 cm 信号探测；再电离的几何与主角（星系还是 AGN）。
6. **宇宙线起源与 PeVatron**："膝"的物理本质；LHAASO 在天鹅座发现 PeV 光子级"超高能宇宙线加速器"，银河系内粒子如何加速到 PeV 以上仍无定论；GZK 截断与超高能宇宙线来源。
7. **高能暂现源中心引擎**：伽马暴（长暴黑洞吸积盘 vs 磁陀星；短暴双中子星并合）、快速射电暴的辐射机制、潮汐瓦解事件（TDE）。
8. **中子星内部结构**：核物质状态方程（最大质量、半径、是否有夸克核）；NICER 半径测量 + 引力波潮汐形变 + X 射线观测的综合约束。
9. **行星系统形成与生命起源**：巨行星迁移、超短周期行星形成；宜居带类地行星大气与生物印记（如 JWST 对 K2-18b 的观测争议）。
10. **星系形成与反馈**：AGN 反馈与星系淬灭、恒星反馈与重子循环、银河系-暗晕关系。
11. **中微子天文**：质量顺序、惰性中微子、超新星爆发中微子、河外中微子源的证认。
12. **多信使协同**：标准汽笛对 H₀ 的独立测量、各信使波段联合约束天体物理模型。

### 1.3 这些问题的解决对基本物理的推动作用

| 前沿问题 | 对基本物理的潜在推动 |
|---|---|
| 暗物质 | 直接超出粒子物理标准模型的新自由度（WIMP、轴子等），或指向修改引力理论；决定 95% 宇宙组分的本质 |
| 暗能量 | "宇宙学常数问题"——量子场论真空能估计与观测值相差 ~120 个量级，是量子论与引力结合的核心难题；其解答可能带来等效原理或广义相对论的修正 |
| 黑洞与引力波 | 强场、动态、非线性引力区的广义相对论检验（引力子质量、额外极化模式）；黑洞信息悖论推动量子引力理论（弦论全息原理等）发展；EHT 视界阴影检验 Kerr 度规 |
| 中子星 | 超核密度物质的状态方程 → QCD 相图、夸克-强子相变、色超导；地面加速器无法企及的密度区间 |
| 宇宙线/高能伽马 | 天体加速器达到 10²⁰ eV，远超 LHC（~10¹³ eV）；超高能光子与中微子的传播检验洛伦兹不变性、量子引力引起的能量依赖速度弥散 |
| 中微子 | 中微子质量起源与质量顺序、惰性中微子存在性；超新星中微子暴检验核心坍缩与中微子物理 |
| 早期宇宙 | 原初引力波振幅直接标定暴胀能量尺度（~10¹⁶ GeV，接近大统一理论）；非高斯性区分暴胀模型 |
| 磁星等极端磁场 | B~10¹⁵ G 超过 QED 临界磁场 B_Q=4.4×10¹³ G，观测检验真空双折射、单光子对产生等强场 QED 效应 |
| 核天体物理 | ⁵⁶Ni/⁴⁴Ti 衰变线、千新星 r 过程谱直接检验核物理与元素起源理论；基本常数（精细结构常数 α）随宇宙时间的演化由类星体吸收线检验 |

总之，天体物理是"极端条件下的天然实验室"——能量、密度、磁场、时标都远超地面实验；其前沿问题的每一次突破（CMB、脉冲星、中微子振荡、引力波、黑洞成像）都曾反哺基本物理，未来在暗物质、暗能量、量子引力、超核密物质等方向上仍是最有希望的突破口。

## 2. 主要望远镜的工作波长范围与光子能量范围

波长—能量换算关系：`E = hc/λ`，即 **E (eV) ≈ 1.24×10⁻⁶ / λ (m)**（或 E(eV) ≈ 1240/λ(nm) = 1.24/λ(μm)）。

| 望远镜 | 波段（工作频率/能量） | 波长范围（米） | 光子能量范围（eV） |
|---|---|---|---|
| **FAST**（500 m 射电望远镜） | 射电，70 MHz–3 GHz | 0.1 – 4.3 | 2.9×10⁻⁷ – 1.2×10⁻⁵ |
| **LAMOST**（郭守敬望远镜，大视场光谱巡天） | 光学，370–900 nm | 3.7×10⁻⁷ – 9.0×10⁻⁷ | 1.4 – 3.4 |
| **ALMA**（阿塔卡马毫米/亚毫米阵列） | 毫米波–亚毫米波，31–950 GHz（波段 1–10，主力 84–950 GHz） | 3.2×10⁻⁴ – 9.6×10⁻³ | 1.3×10⁻⁴ – 3.9×10⁻³ |
| **Spitzer**（斯皮策空间望远镜） | 中/远红外，3–180 μm（IRAC 3.6–8 μm，IRS 5–37 μm，MIPS 24–160 μm） | 3.0×10⁻⁶ – 1.8×10⁻⁴ | 7×10⁻³ – 0.41 |

| **HST**（哈勃空间望远镜） | 紫外–光学–近红外，115–1700 nm（COS/STIS 紫外端 ~115 nm；WFC3/IR 红端 ~1.7 μm） | 1.15×10⁻⁷ – 1.7×10⁻⁶ | 0.7 – 10.8 |

| **EP**（爱因斯坦探针卫星，龙虾眼宽视场 X 射线） | 软 X 射线：宽视场 WXT 0.5–4 keV，后随 FXT 0.3–10 keV | 1.24×10⁻¹⁰ – 4.1×10⁻⁹ | 3.0×10² – 1.0×10⁴ |
| **Chandra**（钱德拉 X 射线天文台） | X 射线，0.1–10 keV | 1.24×10⁻¹⁰ – 1.24×10⁻⁸ | 1.0×10² – 1.0×10⁴ |
| **HXMT**（慧眼硬 X 射线调制望远镜） | X 射线–硬 X 射线，1–250 keV（低能 1–15、中能 5–30、高能 20–250 keV） | 5.0×10⁻¹² – 1.24×10⁻⁹ | 1.0×10³ – 2.5×10⁵ |
| **Fermi**（费米 γ 射线空间望远镜） | γ 射线：GBM 8 keV–40 MeV；LAT 20 MeV–300 GeV（已扩展至 ~1 TeV） | 4.1×10⁻¹⁸ – 1.55×10⁻⁹ | 8.0×10² – 3.0×10¹¹ |

**几点说明：**
- **FAST**：单口径球面射电望远镜，接收机设计覆盖 70 MHz–3 GHz（L 波段 19 波束接收机 1.05–1.45 GHz），通过接收机切换实现宽频段覆盖。
- **LAMOST**：卧式施密特光学光谱巡天望远镜（王-苏反射施密特改正板 + 球面主镜），4000 根光纤，光谱覆盖 370–900 nm。
- **ALMA**：位于智利 Chajnantor 高原的 66 面毫米波干涉阵列；波段 1–10 覆盖 31–950 GHz，波长 0.32–9.6 mm，介于红外与射电之间的"毫米/亚毫米窗口"。
- **Spitzer / JWST**：均为红外优化（低温）空间望远镜。Spitzer 85 cm 主镜、液氦制冷；JWST 6.5 m 镀金分块主镜、位于 L2 点、深冷（~40 K），工作在 0.6–28 μm，核心科学为"第一代星系、恒星形成、系外行星"。
- **Keck / HST**：Keck 为两台 10 m 分块镜面地基望远镜（Keck I/II），光学到红外宽波段（历史上长波光谱仪 LWS 覆盖到 ~25 μm，现役仪器集中于 0.3–5.5 μm）；HST 2.4 m 空间望远镜，覆盖紫外（大气遮挡、地面不可见）到近红外。
- **Swift**：携带三套联动仪器（BAT→XRT→UVOT），专为 γ 暴快速定位与后随观测设计，是典型的"多波段协同"卫星。
- **EP**：中国/欧洲合作的爱因斯坦探针（2024 年发射），采用龙虾眼光学（微孔板 X 射线聚焦）实现 ~3600 平方度超大视场时域 X 射线监测（WXT），配两台后随 X 射线望远镜（FXT，继承 eROSITA 技术）。
- **Chandra / HXMT**：钱德拉为掠入射 Wolter I 型高分辨 X 射线望远镜（角分辨 ~0.5″，亚角秒成像）；慧眼为国内首颗 X 射线天文卫星，准直器调制型高、中、低能探测器组合，兼做偏振测量。
- **Fermi**：LAT 为大面积转换-追踪探测器（γ→e⁺e⁻对），GBM 为闪烁体探测器，联合覆盖 8 keV–300 GeV（~18 个量级中的 X–γ 波段）。

可以看出，从 FAST（米波、10⁻⁶ eV）到 Fermi（10⁻¹⁸ m、10¹¹ eV），现代天文观测已覆盖**从射电到 γ 射线跨越约 17 个量级的波长/能量范围**，天文学名副其实地进入了全电磁波段时代。

## 3. 口径 20 米光学红外望远镜的光学系统设计

20 m 已属于"极大望远镜"（ELT）量级（Keck 10 m → TMT 30 m / ELT 39 m），其设计必须解决三个核心矛盾：**口径远超单块镜面极限、光学到红外的宽波段消色差、大气湍流对分辨率的限制**。我的设计如下。

### 3.1 总体方案：分块主动主镜 + 里奇-克列基昂（R-C）卡塞格林/内史密斯系统 + 自适应光学

**（1）分块式主镜（Segmented primary）——别无选择**
- 单块镜面极限约 8 m 级（VLT 8.2 m、Subaru 8.3 m 已接近运输、退火与重力刚度的工程极限），20 m 必须分块；
- 采用 Keck 验证 30 余年的六角形分块方案：子镜尖对尖尺寸 ~1.4 m，共约 200–230 块（TMT 30 m 用 492 块 1.44 m 子镜，按面积折算 20 m 约 220 块）；
- 每块子镜由主动支撑（作动器）驱动，分块间用**边缘位移传感器**保持共相（phasing），配合**主动光学**（active optics，秒—分钟级低频面形校正）把系统波前误差控制在 ~λ/30 量级；
- 子镜轻量化（蜂窝/薄弯月形）、后面留通风控温，减小镜面湍流（mirror seeing）。

**（2）快焦比反射式 R-C（Ritchey-Chrétien）光学系统**
- **为什么反射式**：透射式系统在 20 m 口径下无论色差、材料均匀性（4 m 级透镜的玻璃一致性已不可能）、重量都不可行；反射系统无色差、天然覆盖 0.3 μm–25 μm 宽波段，只需换镀膜/仪器即可。
- **为什么 R-C**：主、次镜均为双曲面，可同时消除球差与彗差，是现代大望远镜的标准选型（Keck、TMT 同为 R-C）；自然视场可达 10–20 角分，加装折轴改正镜（ADC/宽场改正器）后视场可扩至 ~1°。
- **快焦比**：主镜 f/1~f/1.2（焦距 ~20–24 m），使镜筒总长约 25–30 m，显著压缩圆顶体积与造价（对照：TMT f/1、ELT f/1.05 皆为此因）。
- **次镜**：凸双曲面，直径约 2.5–3 m（ELT M2 为 4.2 m 单镜，工程可行），可五轴精密调节用于调焦、导向与倾斜修正；系统焦比取 f/15–f/20。
- **中央遮挡**控制在直径 ~20% 以内；四叶梁支撑（红外波段要求截面纤细并做低温处理，降低热发射与衍射杂光）。

**（3）焦点布局**
- 两个**内史密斯（Nasmyth）平台**：地平式机架转动的水平轴两端，放置大体积、高稳定的终端仪器（高分辨光谱仪、成像光谱仪）和自适应光学系统——仪器方位恒定、不受重力方向变化影响，是 10 m 级以上望远镜的主流配置；
- 折轴卡塞格林（折轴焦点）用于宽场成像巡天或第二代仪器；
- 保留主焦点（可选）：宽视场巡天（需复杂改正镜组），也可省略以简化系统。

**（4）自适应光学（AO）——20 m 口径的灵魂**
- 20 m 衍射极限在 2 μm 波长为 θ ≈ 1.22λ/D ≈ 0.025″，比典型视宁度（~0.5″）细 20 倍，不配 AO 的 20 m 望远镜分辨率还不如 1 m 望远镜；
- 每个 Nasmyth 焦点配置自适应光学：单共轭 AO（SCAO）用于点源高分辨成像；**多激光导星 + 多层共轭 AO（MCAO/GLAO）**用于大视场像质提升；
- 未来可升级极限 AO（ExAO）做高对比系外行星直接成像（对应 λ/D~0.03″ 的内工作角）。

**（5）红外优化设计**
- 镀膜选择：紫外—光学主要镀铝（0.3–5 μm 高反）；红外优化段镀银/保护银（发射率 ε~0.02，显著降低 3–25 μm 自身热发射，这是中红外灵敏度的主要限制）；
- 镜面与圆顶白天预冷、夜间跟踪环境温度（圆顶视宁度控制），镜面后通风；
- 视场内严格遮挡天空外的所有热源：视场光阑置于真实焦点/中间焦点处（像面挡热），仪器低温（近红外液氮 77 K、中红外 ~4 K）。

**（6）站址与运行**
- 选址于高海拔（>4000 m）、干燥（可 precipitable water vapor <1 mm）、视宁度优异的台址（智利 Armazones/Chajnantor、夏威夷莫纳克亚或中国青海冷湖/西藏这类新兴台址）；
- 地平式（alt-az）机架 + 场旋转补偿（仪器消旋器）。

### 3.2 备选方案与权衡

| 方案 | 优点 | 缺点 | 适用科学目标 |
|---|---|---|---|
| **R-C 卡塞格林/内史密斯**（Keck、TMT 传统） | 技术成熟、镜面数少、造价相对低、光损小 | 自然视场有限（≲20′） | 点源高分辨成像与光谱（恒星、AGN、引力透镜、暂现源后随） |
| **三镜消像散 TMA/五镜系统**（ELT 方案：M1–M5，含两块扁平镜） | 大视场（~10′ 均匀像质）、中间像面可放视场挡热光阑、出射准直光路中放 M4 大变形镜，AO 与仪器设计灵活 | 镜面多、造价高、装调复杂 | 大视场巡天、多目标光纤光谱、红外大视场成像 |
| **四镜宽场系统**（中国 12 m LOT 曾论证） | 平面镜可做大行程变形镜，主动光学潜力大 | 未有大望远镜先例，风险高 | 兼顾宽场与高分辨 |

**结论**：若以"衍射极限高分辨成像 + 高分辨光谱"为核心科学目标（20 m 口径的最大优势——集光面积），我选择**分块主动主镜 + 快焦比 R-C 系统 + Nasmyth 焦点自适应光学**的 Keck/TMT 型成熟方案；若科学目标以大视场巡天为主，则改用 ELT 式五镜消像散系统。两者共同点：**必须分块、必须反射式、必须配主动/自适应光学**——这是由 20 m 口径的工程极限与大气湍流共同决定的。

## 4. 天体 X 射线与伽马射线高能辐射的物理机制

X 射线（~0.1–100 keV）与 γ 射线（>100 keV）来自宇宙中最炽热的气体、最强磁场和被加速到相对论速度的粒子，其产生机制可分为热辐射、非热辐射、核/粒子物理过程与极端场环境新物理四类。

### 4.1 热辐射机制（高温等离子体）

**（1）热轫致辐射（thermal bremsstrahlung，自由-自由辐射）**
温度 T ≳ 10⁷ K（kT ~ 1 keV）的等离子体中，自由电子在离子库仑场中减速发出连续谱，谱形为指数截断：dN/dE ∝ exp(−E/kT)/E。典型天体：**星系团内介质**（T~10⁸ K，几十 keV 内最亮的 X 射线源，用于测宇宙学参量）、恒星冕、年轻超新星遗迹的热激波等离子体。这是"最简单"的 X 射线机制。

**（2）黑体辐射**
中子星表面（T~(1–3)×10⁶ K）的热发射对应 ~0.05–0.3 keV 软 X 射线（观测到的"软过剩"成分）；吸积盘内区多色黑体（~1 keV，黑洞 X 射线双星的"软态"）。黑体温度是中子星半径测量的关键。

**（3）谱线辐射（碰撞激发与复合）**
高温等离子体中 H/He 类离子（如 Fe XXV/XXVI 的 6.7/6.97 keV 线）通过碰撞激发/辐射复合发出特征 X 射线线；线比与线宽用于诊断温度、密度、电离态、湍动速度；**光致电离荧光**：冷物质（吸积盘）被硬 X 射线照射产生 Fe Kα（6.4 keV）荧光线与 20–30 keV 康普顿反射鼓包，是测量黑洞自旋（引力红移展宽）的重要工具。

### 4.2 非热辐射机制（相对论性粒子）

**（4）同步辐射（synchrotron）**
相对论电子在磁场中做回旋运动。特征光子能量 E_syn ≈ 0.7 (B/10 μG)(E_e/100 TeV)² keV——产生 X 射线需要 ~100 TeV 的电子。典型源：**蟹状星云**脉冲星风云（经典案例）、AGN 相对论喷流、超新星遗迹激波加速电子的 X 射线同步"尾巴"。电子能量上限由同步损失与加速时标平衡决定（Hillas 条件之外的"同步极限"~100 TeV 恰好解释许多同步 X 射线源的截断）。

**（5）同步曲率辐射（curvature radiation）**
脉冲星磁层中电子沿强磁场弯曲场线运动（曲率半径 ~10⁸ cm）发出的辐射，是从射电到 X 射线乃至 γ 射线（年轻的"γ 射线脉冲星"）的重要机制。

**（6）逆康普顿散射（inverse Compton, IC）**
相对论电子把低能光子（射电/红外/光学/微波背景）散射到高能：E_IC ≈ (4/3)γ²E_seed。子类：
- **同步自康普顿（SSC）**：电子把自身发出的同步光子再散射（喷流中的"康普顿峰"）；
- **外康普顿（EC）**：散射外部光场（吸积盘辐射、宽线区、尘埃环、CMB）。
是 AGN 喷流、伽马暴、微类星体 γ 射线的主要机制；散射 CMB 的 IC 辐射使**遥远喷流的 X 射线亮度 ∝ (1+z)⁴** 增强，成为发现高红移喷流的工具。

**（7）（热）康普顿化（Comptonization）**
高温（~10⁹ K，"冕"/corona）的稀薄电子气对吸积盘软光子进行多次上散射，形成幂律谱 + 高能截断（截断能标 kT_e）。这是黑洞 X 射线双星"硬态"与 AGN 主幂律成分的标准模型；"内盘黑体 + 康普顿化幂律"双成分是吸积物理的教科书图像。

**（8）非热轫致辐射**
相对论电子（非麦克斯韦分布）与离子碰撞产生幂律硬 X 射线连续谱——太阳耀斑硬 X 射线（厚靶/薄靶模型）的经典机制；也是某些暗物质湮灭通道的预期信号。

**（9）π⁰ 衰变（强子过程）**
宇宙线质子与介质中质子碰撞（pp 碰撞）产生中性 π 介子，π⁰→2γ，谱在 ~70 MeV 处有特征"驼峰"（每个光子 67.5 MeV）。这是区分**质子宇宙线加速源**（SNR、星暴星系、银心）与纯轻子过程的关键判据（Fermi-LAT 在银河系中心等的观测证据）。

**（10）电磁级联**
超高能 γ 光子或电子在辐射场/磁场中引发 e⁺e⁻ 对产生 → 同步/IC → 再对产生的级联，把能谱压到 ~TeV 以下并在观测上呈现可分辨的延展晕。

### 4.3 核与粒子物理线辐射（γ 射线特征线）

**（11）放射性衰变线**：Ia 型超新星 ⁵⁶Co→⁵⁶Fe（847、1238 keV，直接测量爆发核合成）；年轻超新星遗迹 ⁴⁴Ti（68、78、1157 keV，Cas A）；银河系 ²⁶Al（1809 keV）示踪恒星形成历史的"活核合成地图"。
**（12）正负电子对湮灭**：511 keV 线（银心方向的强源），其谱形（正电子素三光子连续谱分量）诊断湮灭环境；正电子来源（放射性核素？暗物质？脉冲星？）仍是悬案。
**（13）核去激发线**：太阳耀斑中被加速的离子撞击介质，产生 ⁴·⁴ MeV（¹²C）、6.1 MeV（¹⁶O）等线；2.223 MeV 中子俘获线（耀斑中子被 H 捕获）。证明耀斑把离子加速到数十 MeV/核子。
**（14）（假说中的）暗物质湮灭/衰变线**：单色 γ 线或连续谱，是间接探测暗物质的重要目标。

### 4.4 极端环境中的新物理

**（15）强磁场 QED 过程**（磁星，B~10¹⁴–10¹⁵ G > B_QED=4.4×10¹³ G）：
- **共振磁康普顿散射**：磁星软 γ 重复暴的主流模型；
- **单光子对产生** γ→e⁺e⁻ 与**光子分裂** γ→γγ：强场中 γ 光子传播被强烈改变，形成"对湮灭光学厚度"决定的谱截止——观测上检验强场 QED；
- 真空双折射引起的偏振旋转（未来 X 射线偏振测量的目标）。
**（16）强引力场效应**：吸积盘内区谱线的引力红移、相对论多普勒展宽与光线弯曲（铁线轮廓测量黑洞自旋）；视界附近辐射的自陷获。
**（17）光球辐射**：GRB 超爱丁顿吸积外流的"污染火球"（photospheric emission，色温黑体成分 ~0.1–1 MeV）；相对论喷流的**多普勒增亮**把内禀辐射放大 δ³–δ⁴ 倍。

### 4.5 典型天体与主导机制对照

| 天体/现象 | 主导辐射机制 |
|---|---|
| 星系团 | 热轫致辐射（10⁷–10⁸ K 气体） |
| 黑洞 X 射线双星 / AGN | 盘黑体 + 冕康普顿化（内区）；喷流同步 + IC（射电噪 AGN） |
| 超新星遗迹 | 激波加热热等离子体（线+连续）+ 电子加速同步辐射 |
| 脉冲星 | 极冠热辐射 + 磁层曲率辐射；脉冲星风云同步 + SSC |
| 磁星 | 磁层重联粒子加速、共振磁康普顿散射 |
| 伽马暴 | 内激波同步 + IC、光球成分；外激波同步/IC |
| 太阳耀斑 | 非热轫致（电子）+ 核去激发线/中子俘获线（离子） |
| 银心 / 星暴星系 | π⁰ 衰变（质子宇宙线）+ 轫致、IC |
| 千新星 / 超新星 | 放射性衰变 γ 线（⁵⁶Co、r 过程核素） |
| 正电子湮灭源 | 511 keV 湮灭线 |

**总结**：热机制（轫致、黑体、谱线）温度由引力能释放决定（吸积、激波、坍缩，virial 温度 ~GMm/R ~keV–100 keV）；非热机制（同步、IC、康普顿化、π⁰衰变）由激波/磁重联加速的相对论粒子驱动；核线辐射直接反映爆发核合成与粒子物理过程；而磁星与黑洞附近则提供检验强场 QED 与广义相对论的天然实验室。
